# AngryMurlocs

Gilden-Helfer für **WoW Forever** (Interface `16001`).

**Version:** 0.4.0  
**Projekt:** https://gitlab.ngit.ovh/murlocs/addon-angrymurlocs

## Features

- Gilden-Kartenpins (Position teilen)
- Berufsliste der Gildenmitglieder
- Wanted-Liste (Spieler-Killer)
- Todes-Toasts und Level-Up-Toasts (Gildenkanal)
- Deutsch / Englisch

Kommunikation läuft über den bestehenden Gilden-Addonkanal (Prefix `GildenRadar` für Kompatibilität).

## Installation

1. Release-ZIP entpacken.
2. Ordner `AngryMurlocs` nach  
   `World of Warcraft\_forever_\Interface\AddOns\` kopieren.
3. Spiel neu starten bzw. Addons neu laden.

## Slash-Befehle

| Befehl | Wirkung |
|--------|---------|
| `/am` | Hauptfenster (Berufe) |
| `/am help` | Hilfe |
| `/am wanted` | Wanted-Liste |
| `/am prof` | Berufsliste |
| `/am share on\|off` | Position teilen |
| `/am map` | Kartenpins an/aus |
| `/am prof share on\|off` | Berufe teilen |

Aliases: `/angrymurlocs`, `/gr`

## Einstellungen

Über die Addon-Optionen (Interface-Optionen / Settings): Teilen, Pins, Toast-Layout.

## Hinweis

Benötigt eine Gilde und Online-Gildenmitglieder mit demselben Addon für Sync-Features.
